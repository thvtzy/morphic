Morphic Playground

Write a Morphic spec; the compiler — compiled to WebAssembly from the same codebase as the CLI — parses, typechecks, and synthesizes an implementation for it in your browser.

Browser build (v0.6 W3): check + synthesis. Synthesis runs the seeded, bounded, LLM-free playground profile and is judged by executed tests only: the panel shows the exact fraction of in-spec tests the interpreter could judge. Formal verification unavailable in browser build — the Z3 verifier and the compiled runner are native-only, so no winner on this page carries a formal verdict.
